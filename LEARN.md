# Learn: FastAPI vs Flask

## 1. Что сделали
- Сравнили FastAPI и Flask на базовом CRUD-приложении
- Реализовали одинаковый функционал в двух фреймворках:
  - Роутинг
  - Валидация данных
  - Тестирование
- Настроили общее хранилище данных для обоих вариантов
- Добавили performance-тесты для сравнения скорости

## 2. Что разобрать
- **ASGI vs WSGI**: FastAPI работает на ASGI (асинхронный), Flask на WSGI (синхронный)
- **Валидация**: Pydantic в FastAPI vs ручная/сторонние либы в Flask
- **Роутинг**: Декораторы vs OpenAPI-интеграция
- **Производительность**: FastAPI быстрее на CPU-bound задачах
- **Экосистема**: Flask имеет больше готовых расширений

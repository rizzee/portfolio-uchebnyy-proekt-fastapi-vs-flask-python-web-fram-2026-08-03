# FastAPI vs Flask Comparison

Этот проект предназначен для сравнения двух популярных Python-фреймворков: FastAPI и Flask. В нем реализованы базовые CRUD-операции, чтобы наглядно показать различия в подходе к разработке, валидации данных через Pydantic и производительности.

### Запуск

Сначала установите зависимости:
```bash
pip install -r requirements.txt
```

Запуск приложения через CLI (введите `fastapi` или `flask` при запросе):
```bash
python main.py
```

### Пример

**FastAPI (автоматическая документация Swagger):**
Перейдите по адресу `http://127.0.0.1:8000/docs` для интерактивного тестирования API.

**Flask:**
API доступно по адресу `http://127.0.0.1:5000/`.

### Тесты

Для запуска всех тестов используйте:
```bash
python -m unittest discover -s tests -v
```
